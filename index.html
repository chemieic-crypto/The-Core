      Spatial Science: Spatial Interpolation Methods

      To model groundwater tables in unmonitored coordinates, the application equips analysts with three industry-standard, high-performance spatial science algorithms. All methods run directly on-device using a dedicated, multi-layer HTML5 projection canvas to calculate values across thousands of raster grid cells:

      Smoothed global

      1. Inverse Distance Weighting (IDW)

      Assumes that wells closer to a grid point have a greater influence on its value than wells further away. Computes a smooth, continuous surface where a cell's value is a distance-weighted average of nearby data points. No single well dominates unless the point lies exactly on top of it.

      Exact tessellation

      2. Nearest Neighbor (Thiessen)

      Assigns a grid cell the exact water level of the single nearest monitoring well. This creates distinct mathematical partitions (Voronoi/Thiessen polygons), modeling local geographic dominance. It is ideal for identifying administrative clusters mapped strictly to their closest observing station.

      Local seamless smooth

      3. Natural Neighbor (Sibson/Shepard)

      Calculates a beautifully continuous grid by weighting cells based on their natural spatial neighbors. Underpinned by local-support math, this interpolator computes seamless gradients between monitoring boundaries and prevents the globally flat bullseye anomalies common to traditional IDW.

      A. IDW Model (Weighted Average) Formula

      // Interpolated value Z_p is a function of Euclidean inverse distance decay:

      Zp = Σ (wi × zi) / Σ wi

      Where weight wi = di-2 is the inverse of the squared Euclidean distance di between the target coordinates and monitoring station i.

      B. Nearest Neighbor Model Formula

      // Interpolated value Z_p is determined exactly by the minimum spatial distance:

      Zp = zk  where  dk = min(d1, d2, ..., dn)

      Where di = √((xp - xi)2 + (yp - yi)2) is the Euclidean distance vector.

      C. Natural Neighbor Model Formula

      // Interpolated value Z_p is a smooth localized function of nearby natural neighbors (Sibson/Shepard):

      Zp = Σ (wi × zi) / Σ wi   [for 4 closest natural neighbors]

      Where the localized support weight wi = ((dmax - di) / (dmax × di))2 is non-zero only for the nearest 4 spatial neighbors within boundary dmax = 1.25 × max(d0..d3).

      Worked Example

      📊 Step-by-Step Interpolation Walkthrough

      A professional breakdown of Inverse Distance Weighting (IDW) and Nearest Neighbor spatial math.

      Consider a target location grid cell P(100, 100) where we want to interpolate the unknown water level depth ($Z_p$). The system detects three active monitoring wells nearby:

      📍 Well A

      Position: (102, 100)

      Measured (zA): 4.50 m

      📍 Well B

      Position: (100, 104)

      Measured (zB): 6.00 m

      📍 Well C

      Position: (95, 100)

      Measured (zC): 3.00 m

      1 Inverse Distance Weighting (IDW) Sample Calculation (Power p = 2)

      We compute the weighted average of the wells based on the inverse square of their Euclidean distances from target point P(100, 100).

      Step A: Calculate Euclidean Distances (di) to well stations:

      • dA = √((100 - 102)2 + (100 - 100)2) = √((-2)2 + 0) = 2.00 units
      • dB = √((100 - 100)2 + (100 - 104)2) = √(0 + (-4)2) = 4.00 units
      • dC = √((100 - 95)2 + (100 - 100)2) = √(52 + 0) = 5.00 units

      Step B: Calculate Distance Decay Weights (wi = 1 / di2):

      • wA = 1 / 22 = 1 / 4 = 0.2500
      • wB = 1 / 42 = 1 / 16 = 0.0625
      • wC = 1 / 52 = 1 / 25 = 0.0400
      • Sum of Weights (Σ wi) = 0.2500 + 0.0625 + 0.0400 = 0.3525

      Step C: Compute Weighted Product Values (wi × zi):

      • Well A: 0.2500 × 4.50 = 1.1250
      • Well B: 0.0625 × 6.00 = 0.3750
      • Well C: 0.0400 × 3.00 = 0.1200
      • Sum of Products (Σ (wi × zi)) = 1.1250 + 0.3750 + 0.1200 = 1.6200

      Step D: Divide Sum of Products by Sum of Weights to get Zp:

      Zp = 1.6200 / 0.3525 = 4.596 meters (mbgl)

      2 Nearest Neighbor (Thiessen Polygon) Sample Calculation

      Nearest Neighbor uses distance minimization to directly map cells strictly to their single closest observer station.

      Step A: Inspect Wells Euclidean Distances from Target Point:

      • Distance to Well A = 2.00 units
      • Distance to Well B = 4.00 units
      • Distance to Well C = 5.00 units

      Step B: Identify the Shortest Distance Vector:

      min(2.00, 4.00, 5.00) = 2.00 units (Well A is at minimum distance)

      Step C: Assign the Nearest Station's Value directly:

      Zp = zA = 4.500 meters (mbgl)

      High-Performance Client-Side Canvas Assembly

      💻 How It Is Computed (Production Code Snippet)

      Below is the exact production algorithm that loops over every coordinate pixel P(x, y) on the canvas grid (~400K iteration iterations) and aggregates weighted values based on the inverse square distance from each active station: 

      // Fast typed arrays are projected to local canvas dimensions first
const numPts = projectedPoints.length; // Active monitoring stations count
const px = new Float32Array(numPts);   // Projected X-coordinate array 
const py = new Float32Array(numPts);   // Projected Y-coordinate array
const pv = new Float32Array(numPts);   // Water level values array

// Interpolation model loop executed for every raster grid pixel (x, y)
let num = 0, den = 0;
let exact = false;

for (let i = 0; i < numPts; i++) {
    const dx = x - px[i];
    const dy = y - py[i];
    const d2 = dx*dx + dy*dy; // Euclidean distance squared
    
    // Avoid division by zero if target coordinate matches well exactly
    if (d2 === 0) { 
        val = pv[i]; 
        exact = true; 
        break; 
    }
    
    // Weight equals the inverse square distance: w = 1 / d²
    const w = 1 / d2;
    num += pv[i] * w; 
    den += w;
}

if (!exact) {
    val = num / den; // Distance-Weighted Average Output
}
      Complexity: O(Pixels × Wells) — completely avoids object lookups in hot loops ⚡ Run Directly On-Device Inside Your Browser

      Below is the exact production algorithm for Nearest Neighbor (Thiessen). It determines water levels strictly based on distance minimization, partitioning spatial grids on-the-fly dynamically into geometric Voronoi ranges: 

      // Fast typed arrays are projected to local canvas dimensions first
const numPts = projectedPoints.length; // Active monitoring stations count
const px = new Float32Array(numPts);   // Projected X-coordinate array 
const py = new Float32Array(numPts);   // Projected Y-coordinate array
const pv = new Float32Array(numPts);   // Water level values array

// Identifies the single nearest well to pixel coordinate (x, y)
let closestD = Infinity;

for (let i = 0; i < numPts; i++) {
    const dx = x - px[i];
    const dy = y - py[i];
    const d2 = dx*dx + dy*dy; // Euclidean distance squared
    
    // Check if this station is closer than previously evaluated candidates
    if (d2 < closestD) { 
        closestD = d2; 
        val = pv[i]; // Value is set exactly to the nearest station's level
    }
}
      Complexity: O(Pixels × Wells) — creates precise, exact Thiessen boundary lines ⚡ Exact Voronoi-Thiessen Grid Partitioning

      Below is the exact production algorithm for Natural Neighbor (Sibson/Shepard approximation). For each coordinates query, it isolates the 4 closest monitoring stations, calculates local-support distance decay weights, and produces beautiful, continuous surfaces: 

      // Keep track of the 4 smallest Euclidean distances to P(x, y) coordinates
let d0 = Infinity, d1 = Infinity, d2 = Infinity, d3 = Infinity;
let i0 = -1, i1 = -1, i2 = -1, i3 = -1;

for (let i = 0; i < numPts; i++) {
    const dx = x - px[i];
    const dy = y - py[i];
    const d2_val = dx*dx + dy*dy;
    
    if (d2_val < d0) {
        d3 = d2; i3 = i2; d2 = d1; i2 = i1; d1 = d0; i1 = i0; d0 = d2_val; i0 = i;
    } else if (d2_val < d1) {
        d3 = d2; i3 = i2; d2 = d1; i2 = i1; d1 = d2_val; i1 = i;
    } else if (d2_val < d2) {
        d3 = d2; i3 = i2; d2 = d2_val; i2 = i;
    } else if (d2_val < d3) {
        d3 = d2_val; i3 = i;
    }
}

if (d0 === 0) {
    val = pv[i0]; // Queries exactly matching coordinates of a well
} else {
    const sd0 = Math.sqrt(d0);
    const sd1 = i1 !== -1 ? Math.sqrt(d1) : Infinity;
    const sd2 = i2 !== -1 ? Math.sqrt(d2) : Infinity;
    const sd3 = i3 !== -1 ? Math.sqrt(d3) : Infinity;
    
    // Choose maximum distance among localized neighbors to establish bounds
    const maxD = i3 !== -1 ? sd3 : (i2 !== -1 ? sd2 : (i1 !== -1 ? sd1 : sd0));
    const d_max = maxD * 1.25 + 0.1;
    
    let num = 0, den = 0;
    
    // Aggregate localized Shepard weight elements for smooth multi-point blend
    const w0 = (d_max - sd0) / (d_max * sd0);
    const w0_sq = w0 * w0;
    num += pv[i0] * w0_sq; den += w0_sq;
    
    if (i1 !== -1) {
        const w1 = (d_max - sd1) / (d_max * sd1);
        const w1_sq = w1 * w1;
        num += pv[i1] * w1_sq; den += w1_sq;
    }
    if (i2 !== -1) {
        const w2 = (d_max - sd2) / (d_max * sd2);
        const w2_sq = w2 * w2;
        num += pv[i2] * w2_sq; den += w2_sq;
    }
    if (i3 !== -1) {
        const w3 = (d_max - sd3) / (d_max * sd3);
        const w3_sq = w3 * w3;
        num += pv[i3] * w3_sq; den += w3_sq;
    }
    
    val = den > 0 ? num / den : pv[i0];
}
      Complexity: O(Pixels × 4) — localized support limits weights to the closest neighbors ⚡ High-Fidelity Local Continuous Blend

      Decadal Fluctuation & Delta Logic

      Comparing water levels of a chosen target period against the mean water level of the preceding 10 years prevents distortion caused by seasonal anomalies or extreme weather. To be processed, a well's record must satisfy strict data density standards (minimum of 5 valid years in the historical decadal period).

      Baseline Calculation Model

      // 1. Mean 10-Yr Historic Baseline average:

      Mean_WLhistoric = Σ (WLhistoric_year) / N     (where N ≥ 5)

      // 2. Groundwater Fluctuation Delta:

      Fluctuation = Mean_WLhistoric - WLtarget_year

      💡 Note: A **positive fluctuation value (+)** indicates the water table has risen closer to the ground surface (improved aquifer conditions), while a **negative fluctuation value (-)** signals aquifer depletion (decline).

      💡 Concrete Example: Decadal Analysis Walkthrough

      Let us evaluate Well UP-HAP-09 for the season Pre-Monsoon 2023 against its 10-year historic average (2013-2022):

      Year 2013 2014 2015 2017 2018 2019 2021 2022 2023 (Target)
      Water Level (m bgl) 14.20 14.50 15.10 13.80 14.90 15.50 14.10 14.70 12.50
      Calculations:
      1. Decadal record availability count = 8 valid years (greater than 5, satisfying CGWB data quality rule).
      2. Mean 10-Yr Historic Baseline = (14.20+14.50+15.10+13.80+14.90+15.50+14.10+14.70) / 8 = 14.60 m
      3. Target Year WL (2023) = 12.50 m
      4. Fluctuation = Mean_WLhistoric - WLtarget_year = 14.60m - 12.50m = +2.10 m (Water table rose by 2.10m, categorized as "Rise: 2 to 4 meters" improvement).
